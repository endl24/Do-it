# 12·13번 UI 미리보기

프로젝트의 지정 Flutter로 app 폴더에서 실행한다.

```powershell
flutter run -t tool/team_ui_preview.dart
```

실제 앱의 main.dart와 분리된 검사용 실행 파일이다. 서버 접속과 영구 저장은 없고 모든 데이터는 메모리에만 있다. 새로 실행하면 초기 테스트 팀으로 돌아온다. 상단 UI 미리보기 배너와 고정된 2026년 9월 21일 날짜로 검사 모드임을 표시한다. 하단 탭은 배치 확인용이며 팀 기능만 검사할 수 있다.

## 확인 순서

1. 초기 ‘캡스톤 3팀’에서 구성원 3명, 공유 4건, 미완료 3건, 초대 코드 7K4M9P를 확인한다.
2. 완료 체크를 변경해 미완료 건수와 카드의 완료 표시를 확인한다.
3. ‘복사’를 눌러 초대 코드와 복사 안내를 확인한다.
4. ‘팀 만들기’에서 빈 이름과 최대 20자 제한을 확인하고 이름을 입력해 생성한다. 테스트 초대 코드가 발급되고 새 팀이 표시된다.
5. ‘초대 코드로 참여’에서 7K4M9P를 입력하면 초기 팀으로 돌아온다. 7K4M9X를 입력하면 코드 오류를 표시하며 재입력이 가능하다. 직접 만든 팀의 코드도 같은 실행 중에 사용할 수 있다.
6. ‘팀 탈퇴’에서 취소·확인·실행 취소와 미참여 상태를 확인한다.
7. 뒤로 가기와 키보드 표시 중 스크롤을 확인한다.

오프라인 화면은 실행 명령 끝에 `--dart-define=TEAM_UI_OFFLINE=true`를 추가해 확인한다. 이는 검사용 고정 상태이며 실제 네트워크 감지가 아니다.

일반 앱으로 돌아오려면 터미널에서 q로 종료한 뒤 -t 옵션 없이 flutter run을 실행한다. 미리보기에서 생성한 팀은 실제 서버 팀이 아니며 일반 앱으로 넘어가지 않는다.
