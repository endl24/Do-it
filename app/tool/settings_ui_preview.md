# 14 설정·계정 UI 미리보기

app 폴더에서 프로젝트 지정 Flutter를 사용한다.

```powershell
flutter run -t tool/settings_ui_preview.dart
```

이 실행 파일은 실제 앱과 분리된 UI 검사용이다. 계정 연동·닉네임 저장·로그아웃·회원 탈퇴는 실제 서버에 요청하지 않는다. 권한 허용과 OS 설정 이동도 가짜 서비스로 처리하며 실제 기기 권한을 바꾸지 않는다. 하단 탭은 배치 확인용이다. 데이터는 실행 세션 내에서만 유지된다.

1. 닉네임을 바꾸고 키보드 완료 또는 입력칸 밖 탭으로 저장 안내를 확인한다.
2. 공백·기호 입력 시 오류와 재입력, 12자 제한을 확인한다.
3. 알림을 눌러 11번으로 이동해 값을 바꾸고 뒤로 돌아와 요약을 확인한다.
4. 권한을 눌러 09번으로 이동해 가짜 권한 허용 후 돌아와 상태를 확인한다.
5. 로그아웃 확인에서 미반영 2건 안내와 취소·확인을 확인한다.
6. 계정 연동으로 다시 연동한 뒤 회원 탈퇴의 삭제 범위와 취소·확인을 확인한다. 실행 취소는 제공하지 않는다.

미연동 상태는 `--dart-define=SETTINGS_UI_UNLINKED=true`, 실패 상태는 `--dart-define=SETTINGS_UI_FAIL=true`를 실행 명령 끝에 붙인다. 실패 옵션은 권한 서비스가 아닌 계정 요청을 실패시킨다.

종료는 q, 일반 앱 실행은 `flutter run`이다. 일반 앱은 실제 계정·권한 서비스가 연결되지 않아 해당 작업 성공을 가장하지 않는다. 알림 변경의 영구 저장과 예약 재계산은 별도 연결이 필요하다.
